# CPI Release 6.3 — At-a-Glance Dashboard

Adds a data-aware At-a-Glance dashboard to the homepage.

## Files

- `css/at-a-glance.css`
- `js/at-a-glance.js`
- `data/homepage.json`
- `scripts/install-at-a-glance.py`

## Widgets

- Top Ranked Clubs
- Biggest Movers
- Trending Clubs
- Upcoming Tournaments

The widgets are designed as reusable dashboard components for future pages.
