# CPI Release 7.30 — Quiksilver Ranking Adjustments

## Summary

Release 7.30 applies a conservative Quiksilver Cup ranking overlay after the 7.29 alias review.

## Scope

- Updates rankings and CPI scores for Quiksilver age/gender groups.
- Adds provisional new-team entries where Quiksilver evidence was strong enough to publish with review flags.
- Adds a ranking adjustment CSV/JSON for audit.
- Updates Quiksilver story/status language to reflect ranking movement.
- Keeps full post-JO recalibration separate.

## Guardrails

- Quiksilver is treated as recent Tier 2 evidence, not a full reset.
- JO results remain the major post-season validation layer.
- 18U Boys remains partially flagged because final/third-place source score details still need confirmation.
- Identity-review entries remain flagged for future audit.
