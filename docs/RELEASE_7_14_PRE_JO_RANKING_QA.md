# Release 7.14 — 14U Boys Refresh and Full Ranking QA

Release 7.14 updates the Pre-JO QA package before publication.

## What changed

- Refreshed 14U Boys ranking records with the same metadata/guardrail layer used by newer groups.
- Added team-depth labels, division-tier labels, tracked-game counts, major-event context, and review flags to 14U Boys.
- Added a full depth-team QA ledger across all live groups, especially groups with 40+ ranked teams.
- Preserved the current 14U Boys ranking order while making it easier to review questionable B/C or lower-division placements.

## What did not change

- Homepage structure
- Rankings page design
- Club pages
- Team pages
- Existing ranking order for non-14U Boys groups

## Review focus

- B/depth teams appearing in upper bands.
- D2/D3 teams that appear above many D1 teams.
- Same-club ladders where B/C teams may be too high.
- Older-age groups with low-game but high-ranking profiles.
