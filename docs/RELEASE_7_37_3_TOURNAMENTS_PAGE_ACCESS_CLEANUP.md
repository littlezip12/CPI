# CPI Release 7.37.3 — Tournaments Page Access Cleanup

## Purpose

Simplify the public tournaments page so users can get directly to the active JO Girls Tournament Journey tool without scrolling past large informational banners.

## Changes

- Removed the large tournament-model hero and summary card from `tournaments.html`.
- Added a compact intro section focused on direct access.
- Promoted Junior Olympics Girls Tournament Journey as the primary tournament tool.
- Added compact secondary cards for:
  - Quiksilver Cup recap
  - Quiksilver ranking audit
  - CPI methodology
- Added `css/tournaments-v7-37-3.css` for page-specific tournament layout polish.

## Unchanged

- No ranking order changes.
- No CPI score changes.
- No team data, club data, logo, story, or model logic changes.
- JO Girls Tournament Journey remains self-contained at `tournaments/jo-girls/`.
