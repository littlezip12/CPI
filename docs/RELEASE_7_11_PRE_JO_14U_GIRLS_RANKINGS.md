# Release 7.11 v3 — Pre-JO 14U Girls Rankings Pilot

This update revises the 14U Girls pilot before publication by auditing same-team aliases and correcting Lamorinda's internal team structure.

## What changed from v2

- Corrected Lamorinda alias logic:
  - Lamorinda A remains the A/primary team.
  - Lamorinda B and Lamorinda Gold are consolidated as the B-level profile.
  - Lamorinda C remains the C-level profile.
- Re-audited multi-team clubs for duplicate names versus true A/B/C depth teams.
- Preserved the Futures Super Finals / US Club Championships peer-weighting model.
- Preserved 12U Boys, 14U Boys, homepage, rankings UI, clubs, and team pages.
