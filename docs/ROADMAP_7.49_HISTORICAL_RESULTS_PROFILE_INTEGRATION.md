# CPI 7.49 — Historical Results Completion & Profile Integration

## Purpose
Turn the completed-tournament bank into useful, source-traceable profile context without allowing historical data to change current rankings automatically.

## Delivered
- Positional score-column inference for completed-event tables with blank score headers.
- Pool, seed, ordinal, and winner/loser prefixes stored as source metadata instead of team-name text.
- Explicit footer placements and placement-game finishes.
- Separate historical profile runtime for canonical teams and clubs.
- Team and club profile sections with results, appearances, records, finishes, and archive links.
- Archive filters for tournament, division, age, gender, status, team, and club.
- Profile and source links on archived games.
- Blocking validation that preserves ranking quarantine.

## Coverage at release
- 18 of 25 historical divisions banked.
- 787 archived games.
- 769 verified final results.
- 116 ranked teams with linked history.
- 82 clubs with linked history.
- Seven divisions remain pending source access.

## Policy
Historical profile display does not enable ranking evidence. Any future use in ranking recommendations requires an explicit tournament-level approval and a separate reviewed release.
