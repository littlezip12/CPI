# Install WPI 7.55.4

1. Apply the cumulative ZIP over the committed pushed WPI baseline.
2. Run `./release-check`.
3. Commit only after the exact final line `CPI release check passed.`
4. Push and wait for GitHub Pages to deploy.
5. Begin at `https://littlezip12.github.io/CPI/live-login.html`.
6. In the current demo configuration, choose **Continue to local sandbox**.
7. Do not add Supabase or GroupMe secrets to GitHub.

This release uses the existing repository and Terminal workflow. It does not require a second GitHub repository or a different Terminal setup.
