# CPI Ranking Pipeline Data Scaffolding

This folder defines the architecture for future ranking updates.

Release 7.18 does not execute a ranking model or change rankings. It creates schema and template files for future post-JO and next-season ranking workflows.

## Folders

- `schemas/` — canonical JSON schemas for pipeline objects
- `templates/` — starter templates for future data files
- `model-weighting-7-18.json` — current ranking logic and weighting configuration

## Future expected folders

- `snapshots/` — saved ranking releases
- `source-registry/` — tournament source metadata
- `review-packets/` — generated manual review outputs
