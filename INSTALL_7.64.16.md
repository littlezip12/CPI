# WPI 7.64.16 — Player Stats Visual Polish

## Install

Unzip the patch over the current pushed WPI 7.64.15 repository, then run:

```bash
./release-check-live-7.64.16
./release-check-clean
```

No Supabase migration, Edge Function deployment, secret update, or data operation is required.

## Scope

- Explicit white/light surfaces for desktop Player Stats comparison tables.
- Lighter stat-label cells and soft blue-gray section bands.
- Subtle alternating row shading and hover tracking.
- Slightly larger table text and spacing for laptop/desktop readability.
- Keeps the 7.64.15 roster accuracy, identity, privacy, mobile Player Stats, scoring, GroupMe, and tournament behavior unchanged.
