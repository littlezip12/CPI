# WPHQ 7.64.42 ECC Team Journey History Correction

Adds completed games to the selected team's ECC Team Journey without changing the Google source adapter or tournament routing.

For every selected team, the Team Journey now shows a **Games played** section with:
- Win / Loss / Tie
- opponent
- game number
- date and time
- team-perspective final score
- venue + Google / Apple / Waze links

The existing Tournament Record, next scheduled game, route scenarios, team pinning, and Google live refresh remain unchanged.

This is an overlay for the 7.64.42 ECC Google live-source candidate and should be validated before commit/push.
