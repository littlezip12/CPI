# California Polo Index — Phase 1 Fresh Repo

This is the clean Phase 1 launch package for a brand-new GitHub Pages repository.

## What is included
- Dynamic homepage
- 14U Boys rankings landing page
- Full 14U Boys rankings table
- Dynamic team pages
- Dynamic club pages
- Local generated club badges for all clubs
- User-confirmed Lamorinda logo
- Club-color themed pages
- No overall record
- No division filters
- Best win formatting like `SD Dons A (10–5)`

## GitHub setup

Create a new public repo, recommended name:

`cpirankings`

or:

`california-polo-index-v2`

Then upload the files/folders from this package directly to the repo root.

The repo root should contain:

- `index.html`
- `14u-boys.html`
- `rankings.html`
- `clubs.html`
- `team.html`
- `club.html`
- `methodology.html`
- `app.js`
- `data.js`
- `styles.css`
- `assets/`
- `data/`
- `.nojekyll`

Do not upload the ZIP itself. Do not upload a parent folder.

## Turn on GitHub Pages

Settings → Pages → Deploy from branch → main → / root → Save

## First test URLs

After Pages deploys, test:

- `/index.html`
- `/rankings.html`
- `/team.html?team=lamorinda-b`
- `/club.html?club=lamorinda`
- `/assets/logos/lamorinda.png`

If those work, the repo is clean and ready for the next build pass.
