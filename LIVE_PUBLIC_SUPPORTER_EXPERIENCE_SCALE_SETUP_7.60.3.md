# WPI Live 7.60.3 — Public / Supporter Experience at Scale

## Operating model
- Following is keyed to stable WPI team-family identity and may span clubs.
- A directory follow can exist before the club/team is onboarded to WPI Live.
- Live games appear only when an active Live team has been explicitly linked to the same family identity.
- Following remains read-only. It never creates `live_team_members`, scorer sessions, roster authority, GroupMe authority, or club/team administration.
- Existing direct Lamorinda follows remain compatible.

## UX
`live-following.html` provides My Teams, full WPI directory discovery, Club/Age/Group filters, one chronological Live/Upcoming/Recent Finals feed, recap/stat links, and tournament/weekend summaries.
