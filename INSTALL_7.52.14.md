# WPI 7.52.14 — Club Website Audit Wave 1

This patch is installed over WPI 7.52.13.

It adds 15 verified official club website links, records website verification status for all 182 canonical clubs, and creates a complete audit queue for the remaining missing or ambiguous links. Rankings, CPI values, tournament results, placements, and identities are unchanged.

Run `./release-check` after installation and commit only when the final line is `CPI release check passed.`
