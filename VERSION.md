# WPI 7.63.7 — Promotional Access & Adoption Operations

WPI 7.63.7 turns the existing no-card Team Insights preview foundation into a Platform Owner operating workflow. The Platform Owner can schedule, edit, pause and reactivate free Team Insights preview windows for one team, an entire organization, or the WPI platform; optionally reference a team tournament/weekend; and use 3/7/14-day shortcuts. Eligible Supporters automatically unlock Team Insights only during the configured window and automatically return to Free Supporter access after it ends. No payment method is collected, no subscription is created, Stripe remains disabled, and no infrastructure tier change is required.
