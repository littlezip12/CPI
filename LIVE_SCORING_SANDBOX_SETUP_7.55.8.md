# WPI Live Scoring Sandbox — 7.55.8

## Resetting a test
Use **Reset test game** at any point before, during, between quarters, or after a game. The control returns the sandbox to pregame setup.

The reset clears the current score, quarter, time, plays, timeline, recap, and mock GroupMe message log. It intentionally preserves the selected team, game setup defaults, roster, cap numbers, and saved default starting lineup so another full test can begin immediately.

## Pilot flow
The pilot remains configured for **Lamorinda A 14U Boys** by default. Add or edit players, select the exact age-appropriate starting lineup, submit plays without a second confirmation, and use **End quarter** to advance to the next lineup.
