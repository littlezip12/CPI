# CPI 7.52.4 — WPI Homepage Redesign

This release replaces the legacy homepage with the approved Water Polo Index design.

## Scope

- Static photo hero with direct links to rankings and tournament results.
- Team and club search with linked suggestions.
- Dynamic ranked-team, club, ranking-group, and JO-finish totals.
- Boys/Girls ranking cards for 12U, 14U, 16U, and 18U.
- Completed Junior Olympics results preview by category, age, division, and subdivision.
- Featured club profiles and a clickable regional club map.
- Region and search query support on the club directory.
- Linked methodology and latest-update modules.
