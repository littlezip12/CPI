# WPI 7.55.6 — Live Scoring Sandbox Setup

## Entry

Open `live-login.html`, then continue to the local sandbox while connected authentication remains disabled.

## Manual scrimmage setup

Choose the team age group. The lineup rule is enforced automatically:

- 10U and 12U: one goalie and five field players (six starters)
- 14U, 16U and 18U: one goalie and six field players (seven starters)

The Q1 starting lineup is saved as the team default and will be preselected when the next sandbox game is created. Quarter two and later preselect the prior quarter lineup.

## Game flow

1. Select the exact valid starters and begin the game.
2. Record each event with the single compact form. Submit records immediately; there is no confirmation screen.
3. Tap **End quarter**. WPI records the quarter end and opens the next-quarter lineup using the previous lineup as the default.
4. Use Undo or score correction after any mistaken entry.

GroupMe remains preview-only until the secure backend is connected. Sandbox data cannot update rankings or official tournament records.
